# 소개 페이지

이 저장소는 개발자 개인 포트폴리오 웹 페이지입니다. HTML, CSS, JavaScript를 사용해 만든 간단한 자기소개 사이트로, 다크 모드 전환 기능과 섹션별 정보가 포함되어 있습니다.

## 포함된 파일

- `index.html` - 포트폴리오 페이지의 메인 HTML 파일
- `style.css` - 페이지 스타일과 반응형 레이아웃 정의
- `script.js` - 다크 모드 토글 및 스크롤 네비게이션 기능 구현
- `favicon.ico` - 페이지 아이콘
- `profile.jpg` - 프로필 이미지

## 주요 내용

페이지에는 다음과 같은 정보가 포함되어 있습니다.

- 소개
- 학력
- 기술 및 자격증
- 경험
- 프로젝트
- 관심사
- 목표
- 연락처

## 실행 방법

1. 저장소를 클론하거나 파일을 로컬로 복사합니다.
2. `introduce` 폴더 안의 `index.html` 파일을 브라우저에서 엽니다.

또는 VS Code에서 아래 방법 중 하나로 실행할 수 있습니다.

- `index.html` 파일을 열고 Live Server 확장 프로그램을 사용해 실행
- 파일을 브라우저로 드래그하여 열기
